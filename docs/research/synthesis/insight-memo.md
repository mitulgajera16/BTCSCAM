# Insight Memo — Phase-Community Research Synthesis

**Date:** 2026-08-11 · Synthesized from `01`–`05` (see `../00-program.md`). Format per insight: **claim → evidence → decision**. Every insight terminates in **ADOPT** (flows into `prd-delta.md` / `phase-community-roadmap.md`), **REJECT** (with reason, kept for the record), or **PARK** (backlog).

---

**1. The free-tool-feeds-paid-business architecture is the proven category shape, and HIBP — not TRM — is our role model.**
Evidence: 02 — Chainabuse earns $0 directly; all gates are application-gated into TRM ($218M+ raised, $1B valuation); HIBP is a one-person trust brand converting via one disclosed consumer product. → **ADOPT.** Keep the core free forever; model conversion on HIBP, not enterprise sales.

**2. Human-only trust-state promotion is the industry-verified design; community verification works only when votes are reputation-staked.**
Evidence: 01 — only Bitcointalk runs community verification, and only because false accusers face symmetric reputation damage; Chainabuse lets the crowd flag but staff assign every confidence score. → **ADOPT.** Keep human-only promotion (already built); make verify-votes reputation-bearing — a corroboration that's later overturned must cost ladder standing. Publish our promotion rubric HIBP-style (his 5-question checklist is the precedent).

**3. A contributor status ladder is unoccupied territory across the entire landscape.**
Evidence: 01 — no scam platform runs badges, points, or levels; the working substitutes (closure narratives, chosen-name attribution, Bitcointalk reputation) are all partial. 03 — hunters demonstrably work for status currencies. → **ADOPT.** The Watchmen ladder is a genuine differentiator; name Corroborators on dossier pages (real credit).

**4. Reporter motivation is protect-the-next-victim fused with shame-conversion; money is explicitly disclaimed.**
Evidence: 03 — "I know I'm dumb but let me put this out so no one else falls for it" (+ ~80 "so no one else" posts in 72 days); recovery explicitly disclaimed by reporters; Bitcointalk hunters paid in outcomes, thanks, identity. → **ADOPT** copy framing: reporting = protecting the next person, never admitting victimhood. → **REJECT** any monetary/token incentives — now evidence-backed, not just editorial law: money attracts farmers and repels the motivation that actually exists.

**5. The reporting black hole is the single loudest complaint; visible feedback is the product, not a feature.**
Evidence: 03 — IC3/FTC "confirmation number then silence forever" across venues; HN: "the 'acted upon' part needs to be highlighted in tangible ways, otherwise… fewer reports." 05/F6 — "Nothing succeeds like the feeling that you're succeeding." → **ADOPT** as the core positioning: BTCSCAM is the anti-black-hole. Per-report status transitions visible to the reporter, plus a public outcome counter ("N registrar takedowns confirmed") the moment we have one.

**6. Cold start is always supply-side; the empty form never bootstraps.**
Evidence: 01 — zero platforms started as a bare submission form; Chainabuse launched with six partners and "hundreds of reports" pre-loaded; HIBP launched atop existing corpora. → **ADOPT.** Seed /reports/open editorially (10–15 documented public cases) and run Monday Sweep as *published content* before promoting community features. Community activation is Stage D, not Stage A (see roadmap).

**7. /check must be evidence-first; single trust scores are the documented failure.**
Evidence: 03 — ScamAdviser distrusted in both directions with receipts (91/100 "high trust" on a confirmed scam; violin-maker false positive); HN: "people take false negatives as proof that things are OK." 04 — HIBP's zero-navigation same-surface verdict. → **ADOPT.** /check shows evidence (report count, blacklist hits, domain signals, dossier links), never a composite score; verdict on the same surface, no account, no interstitial.

**8. Dossiers should speak the victim's phrase grammar, because reporters already write SEO warnings by hand.**
Evidence: 03 — "if someone searches for phrases like 'task job', 'bulk purchase', 'complete tasks before withdrawal'… I hope they find this thread"; mods enforce URL-required "to help future victims." 05/F3 — target the desire's language ("is X a scam"), not category language. → **ADOPT.** Add a phrases/aliases field to the incident schema; title pattern already matches ("what happened and what's verified").

**9. Anti-recovery-scam defense is table stakes on every victim surface; free-text testimonial surfaces are how checkers die.**
Evidence: 03 — a live recovery-scam solicitation captured inside a victim help thread; ScamAdviser's reviews "FILLED with reviews promoting recovery scammers"; r/CryptoScams runs an AutoMod warning on every thread. 02 — the dirty-verdict abstention. → **ADOPT:** recovery-scam warning banner on every dossier + dirty verdict; explicit on-page policy line "We sell nothing on this page on purpose — anyone promising recovery is running the second half of the scam." → **REJECT** public free-text comments/reviews/testimonials on any surface, permanently. Evidence chips + verify-votes only.

**10. Defamation is managed by object choice: the ledger names addresses/domains/handles — never legal names.**
Evidence: 01 — every surviving aggregator publishes objects, not people; only personally-liable journalists name humans; Chainabuse adds safelist + hedge language. → **ADOPT** as constitution law: human names appear only in bylined editorial articles; ship a known-good safelist and a dispute/right-of-reply lane BEFORE community promotion mechanics go live.

**11. Funnel surfaces adopt the HIBP disclosure grammar; SeedBook first, Bitwill after the pattern is proven.**
Evidence: 02 — funnel-surface spec with Troy Hunt's language as benchmark ("Clearly, this is a commercial relationship… I've paid retail prices for years"); 05 — inheritance guide deliberately held to batch 2. → **ADOPT** the 02 spec table verbatim; first-person disclosure copy; dirty-verdict page sells nothing; newsletter (when revived) carries one labeled house slot max.

**12. Two-surface architecture: Marl-grade check, hunter-grade contribute.**
Evidence: 05/F5 — the median user is distracted and frightened (one-line verdict above the fold); the contributor minority wants identity, density, outcomes. 04 — GOV.UK one-thing-per-page for the stressed public; MoJ dense-view for professionals (/desk). → **ADOPT.** Never average the two audiences into one page.

**13. The guide calendar is FIRST 4: phishing recognition + hardware authenticity (publish as a pair in the live Coldcard window), recovery-service scams, seed storage.**
Evidence: 05 — autosuggest-verified demand; no evergreen competitor on phishing; recovery-scam SERP partly colonized by the scammers themselves ("near me" shoppers queued for the double-scam); seed storage = 10/10 suggest slots + SeedBook funnel. → **ADOPT** as the content calendar. Inheritance guide (Bitwill) waits until disclosure is exercised on SeedBook links.

**14. Brand-clone risk is proven, not hypothetical.**
Evidence: 03 — chainabuse.report phishing clone intercepted Chainabuse's brand within weeks, amplified by fake reviews on ScamAdviser. → **ADOPT** ops: register adjacent TLDs/typos of btcscam, publish a canonical-domain notice on-site, and monitor for clones.

**15. Publishing our own outcome metrics would be a first-in-category trust move.**
Evidence: 04 — none of eight design precedents publish measured outcomes; report completion rate, verify-vote participation, and time-to-verification are measurable without surveilling users. → **ADOPT** in principle; **PARK** the exact metric set and threshold (small numbers can hurt — revisit when volume exists; open question flagged in 02).

**16. Real-time browser-extension / API surface for /check.**
Evidence: 03 wish list — "built into the browsers… warn real time"; first comment on a Show HN checker was "Is there an API?"; but adversarial risk (scammers probing the blocklist) and solo bandwidth. → **PARK.** Revisit after Phase Community ships; the public /api/incidents feed already covers the citation use case.

**17. Reconcile the Coldcard loss figure before any new content cites it.**
Evidence: 05 — Decrypt now reports "near $130M" vs our dossier's $116M launch figure. → **ADOPT** ops: update the dossier with an as-of-dated range and correction-log entry this week.

**18. Evidence gaps to close honestly: X/Twitter demand, Trustpilot complaints, r/scams exact rules, archive pass.**
Evidence: 03/01 method notes — X paywalled (402), Trustpilot/ScamAdviser 403, reddit.com blocks fetching, all archive services rate-limited (quotes.csv archive_url column empty). → **ADOPT** ops: re-run the archive pass from another network before any quote is published in an article; manual capture of r/scams rules. X remains **PARK**.
